01 / Embedded systems

ハンターカブ 燃費計＋マルチメーター

2025年式CT125を対象とした後付けの車載情報表示装置。純正メーターだけでは得にくい燃料消費に関する情報を表示し、日常の走行をサポートすることを目指す。

TYPE
組込み・車載機器
STATUS
机上試作・実車検証前
GOAL
将来的な製品化

解決したい課題

  • 瞬間・平均燃費や航続可能距離を把握したい。
  • 純正配線を切断せず、既存の車両に追加できる構成を目指す。

設計・開発の工夫

  • ECUデータを起点とした燃費演算と表示処理を分離。
  • 総走行距離と総燃料消費量から平均燃費を計算する方針。
  • 仮想ECUで机上試験を先行し、実車接続のリスクを低減。

現在の進捗

Raspberry Pi Picoによる仮想ECUを利用した初期試験に成功。XIAO ESP32-C6を本体マイコンとして採用。

今後の検証

実車ECUの通信方式・取得可能データ、燃費精度、車載電源対策、防水・耐振動性を確認する。瞬間／平均燃費、推定残量、航続距離、回転数、電圧は目標機能であり、実車での取得・表示は未確認。

02 / Workflow automation

LINE備品管理システム

大学の山岳サークルで共同利用する装備の貸出状況を管理するためのシステム。日常的に使うLINEを入口にして、利用者が少ない操作で貸出・返却できるよう設計した。

TYPE
Webアプリ・業務自動化
STATUS
導入準備中
DEPLOYMENT
2026年12月 運用開始予定

解決したい課題

  • 誰がどの備品を借りているか把握する。
  • 貸出・返却記録を手作業で管理する負担を減らす。

主要機能・設計

  • QRコードによる備品識別、LINE上の貸出・返却操作。
  • 返却予定日、使用状況、貸出履歴の管理。
  • 白と青を基調としたスマートフォン向けUI。

技術的な工夫

貸出台帳を単一の正とし、GASの排他制御で二重貸出を防止する設計。署名付きリクエスト、重複処理の防止、利用者・期限の検証に対応する。

現在の進捗

システム実装とUI改修を進め、2026年11月29日に備品登録、12月に運用開始予定。改修版のLINE実機表示・本番運用の確認は今後の課題。

03 / Algorithm design

LINE審議スケジューラー iFinder_β

山岳サークルの山行計画を確認する審議のため、複数人の空き時間と組織独自のルールを同時に満たす日程・担当者の組み合わせを探索するシステム。

TYPE
制約付きスケジューリング
STATUS
実装・性能改善段階
INTERFACE
LINE連携・Web UI

解決したい課題

  • 複雑な参加条件を人力で照合する負担。
  • 特定の審議担当者に負担が偏る問題。
  • 複数回の審議で情報を継続して引き継ぐ必要性。

制約とアルゴリズム

  • 4人の審議者構成、2時間以内、日・週単位の回数上限を考慮。
  • 前回からの担当者の引継ぎを維持しつつ、回数の偏りを抑える。
  • 計画者の空き時間や出発期限を先に絞り込み、候補探索を効率化。

ユーザー体験

オート／マニュアルモード、対面／オンラインの区別、候補の追加表示、進捗表示、履歴管理。LINEから利用できる日本語UIを設計。

現在の進捗

PythonからGoogle Apps Scriptへ移植し、候補探索・履歴・UI・高速化を継続改善。月別データ参照やキャッシュ活用を検討・改善してきた。定量的な時間短縮効果は未計測。
